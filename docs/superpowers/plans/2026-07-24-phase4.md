# Phase 4 实施计划：有状态服务逐个进集群

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将 docker-compose 中的 4 个有状态服务（MySQL → ClickHouse → Milvus → Kafka）逐个迁移到 k3s，使用 PVC + local-path provisioner，最终 docker-compose 完全下线。

**Architecture:** 每个服务独立迁移，使用 k3s 自带的 local-path provisioner 创建 PVC，数据通过 rsync 从 data/ 目录迁移到 PV。ExternalName 逐个更新指向 k3s 内部 Service DNS。Kafka 采用新旧双跑的生产级切流方式。

**Tech Stack:**
- k3s (单节点)
- local-path provisioner (k3s 自带)
- PVC + StatefulSet / Deployment / Operator
- Helm (ClickHouse Altinity, Milvus)
- Strimzi Kafka Operator (KRaft 模式)
- ExternalName Service (collectors namespace)

## Global Constraints

- **存储**: PVC + local-path provisioner（k3s 自带）
- **镜像架构**: linux/arm64
- **镜像拉取策略**: imagePullPolicy: Never（与 Phase 2/3 一致）
- **命名空间**: data（所有状态服务统一在一个 namespace）
- **单副本**: 一律单副本，不做伪 HA
- **Ollama**: 不进集群，通过 ExternalName 访问
- **数据目录**: data/ 下的现有数据不删除，迁移后保留作为备份
- **迁移手法**: rsync 一次性数据迁移，不停机
- **资源预算**: VM 28GB，峰值约 35GB（新旧双跑时）

### Task 1: 创建 MySQL StatefulSet

**Files:**
- Create: `infra/k8s/data/mysql-statefulset.yaml`
- Create: `infra/k8s/data/mysql-secret.yaml`

**Interfaces:**
- Consumes: 无（独立服务）
- Produces: `mysql.data.svc.cluster.local:3306`，PVC `mysql-pvc`

- [ ] **Step 1: 创建 MySQL Secret**

创建 `infra/k8s/data/mysql-secret.yaml`，管理 MySQL 密码：

```yaml
apiVersion: v1
kind: Secret
metadata:
  name: mysql-secret
  namespace: data
type: Opaque
stringData:
  root-password: "minioadmin"
  database: "streampark"
```

- [ ] **Step 2: 创建 MySQL StatefulSet**

创建 `infra/k8s/data/mysql-statefulset.yaml`：

```yaml
apiVersion: apps/v1
kind: StatefulSet
metadata:
  name: mysql
  namespace: data
spec:
  serviceName: mysql
  replicas: 1
  selector:
    matchLabels:
      app: mysql
  template:
    metadata:
      labels:
        app: mysql
    spec:
      containers:
      - name: mysql
        image: mysql:8.0
        imagePullPolicy: Never
        ports:
        - containerPort: 3306
          name: mysql
        env:
        - name: MYSQL_ROOT_PASSWORD
          valueFrom:
            secretKeyRef:
              name: mysql-secret
              key: root-password
        - name: MYSQL_DATABASE
          value: streampark
        - name: TZ
          value: Asia/Shanghai
        volumeMounts:
        - name: mysql-data
          mountPath: /var/lib/mysql
        resources:
          requests:
            cpu: 500m
            memory: 1Gi
          limits:
            cpu: 1000m
            memory: 1Gi
      volumes:
      - name: mysql-data
        persistentVolumeClaim:
          claimName: mysql-pvc
---
apiVersion: v1
kind: PersistentVolumeClaim
metadata:
  name: mysql-pvc
  namespace: data
spec:
  accessModes: [ReadWriteOnce]
  storageClassName: local-path
  resources:
    requests:
      storage: 10Gi
---
apiVersion: v1
kind: Service
metadata:
  name: mysql
  namespace: data
spec:
  clusterIP: None  # Headless for StatefulSet
  ports:
  - port: 3306
    targetPort: 3306
    name: mysql
  selector:
    app: mysql
```

### Task 4: 创建 Kafka（Strimzi + KRaft）

**Files:**
- Create: `infra/k8s/data/kafka-strimzi.yaml`

**Interfaces:**
- Consumes: 无（独立服务）
- Produces: `kafka.data.svc.cluster.local:9092`

- [ ] **Step 1: 创建 Strimzi Kafka CR**

创建 `infra/k8s/data/kafka-strimzi.yaml`：

```yaml
apiVersion: kafka.strimzi.io/v1beta2
kind: Kafka
metadata:
  name: kafka
  namespace: data
spec:
  kafka:
    version: 3.7.0
    replicas: 1
    listeners:
    - name: plain
      port: 9092
      type: internal
      configuration:
        bootstrap:
          service:
            name: kafka-bootstrap
    config:
      KAFKA_BROKER_ID: 1
      KAFKA_CONTROLLER_QUORUM_VOTERS: 1@kafka-kafka-bootstrap.data.svc.cluster.local:9093
      KAFKA_CONTROLLER_LISTENER_NAMES: CONTROLLER
      KAFKA_LISTENER_SECURITY_PROTOCOL_MAP: "CONTROLLER:PLAINTEXT,PLAIN:PLAINTEXT"
      KAFKA_INTER_BROKER_LISTENER_NAME: PLAIN
      KAFKA_OFFSETS_TOPIC_REPLICATION_FACTOR: 1
      KAFKA_LOG_DIRS: /var/lib/kafka/data
      KAFKA_HEAP_OPTS: "-Xmx1G -Xms1G"
      KAFKA_NODE_ID: 1
      KAFKA_PROCESS_ROLES: broker,controller
    storage:
      type: persistentVolumeClaim
      persistentVolumeClaim:
        claimName: kafka-pvc
        storage: 20Gi
        storageClassName: local-path
    resources:
      requests:
        cpu: 500m
        memory: 2Gi
      limits:
        cpu: 1000m
        memory: 2Gi
---
apiVersion: kafka.strimzi.io/v1beta2
kind: KafkaTopic
metadata:
  name: all-existing-topics
  namespace: data
spec:
  kafkaName: kafka
---
apiVersion: v1
kind: Service
metadata:
  name: kafka-bootstrap
  namespace: data
spec:
  type: ClusterIP
  ports:
  - name: plain
    port: 9092
    targetPort: 9092
  - name: controller
    port: 9093
    targetPort: 9093
  selector:
    app: kafka-kafka
```
